# Bijouterie OS: портфолио в виде рабочего стола

Сайт Екатерины Сысоевой, оформленный как операционная система: иконки на рабочем столе, окна, панель задач, меню «Пуск», терминал.
Чистые HTML, CSS и JavaScript, без сборки и без библиотек. Открывается двойным кликом по `index.html`.

## Структура проекта

```
site-desktop/
  index.html          каркас страницы: заставка, рабочий стол, панель задач
  assets/             картинки, фото, резюме (PDF)
  css/
    base.css          палитра (переменные :root) и общие настройки
    desktop.css       фон рабочего стола, иконки, экран загрузки
    window.css        окна и всё, что внутри окон
    taskbar.css       панель задач, меню «Пуск», часы
  js/
    data.js           ВЕСЬ текст сайта (имя, навыки, проекты, опыт). Правим здесь
    wm.js             менеджер окон: открыть, закрыть, перетащить, растянуть, свернуть
    taskbar.js        панель задач, «Пуск», часы
    desktop.js        иконки на рабочем столе
    apps.js           программы: Обо мне, Проекты, Навыки, Опыт, Резюме, Контакты и окна проектов
    terminal.js       программа «Терминал» с командами
    main.js           запуск: рисуем стол, убираем заставку, открываем первое окно
```

## Как это работает

1. `main.js` рисует иконки (`desktop.js`) и панель задач (`taskbar.js`).
2. Двойной клик по иконке вызывает `OS.wm.open('id')`: менеджер окон (`wm.js`) создаёт окно и просит программу из `apps.js` нарисовать содержимое.
3. Текст берётся из `data.js`, поэтому правки содержания не требуют лезть в код программ.
4. На телефоне окна разворачиваются на весь экран, иконки открываются одним касанием.

## Как добавить программу

В конце `js/apps.js`:

```js
OS.apps.register({
  id: 'hobby', title: 'Хобби', label: 'Хобби', icon: '🌷', size: { w: 480, h: 320 },
  render(body) { body.innerHTML = '<h2>Хобби</h2><p>Цветы и бисер.</p>'; },
});
```

Иконка появится на рабочем столе и в меню «Пуск» сама. Чтобы программа не показывалась на столе (как окна проектов), добавьте `desktop: false`.

## Как поменять внешний вид

- **Цвета:** `css/base.css`, блок `:root`.
- **Иконки:** сейчас эмодзи (поле `icon`). Их можно заменить на картинки из Figma.
- **Макет из Figma:** когда он будет готов, я перенесу расположение, шрифты и цвета в `css/`.
